## 👩‍💻 O meni

Volim da razumem kako sistem zaista radi, bilo da je to aplikacija sa jasno razdvojenim slojevima, upit koji iz običnih tabela izvlači obrasce ili ESP32 koji razlikuje pravi nestanak struje od sumnjivog.

Trenutno tražim posao kao **junior developer** ili **data / BI analitičar**. Razvijam desktop aplikacije u C#-u, radim sa SQL Serverom i OLAP kockama, a pišem i automatizovane testove i IoT prototipove.

📍 Srbija

### ⚡ [iot-power-outage-detection](https://github.com/jovana1408/iot-power-outage-detection) — IoT detekcija nestanka struje
ESP32 (Wokwi simulacija) beleži nestanke i povratke napajanja, upisuje ih u Firebase i šalje Telegram obaveštenja. Prepoznaje anomalije, na primer previše nestanaka u kratkom roku ili sumnjivo kratke prekide koji liče na sabotažu senzora. Web dashboard prikazuje forenzički log, statistiku i grafikon.
